# SVM Cats vs Dogs Classifier

This project implements a Support Vector Machine (SVM) classifier to distinguish between cats and dogs using HOG feature extraction.

## Features
- Image preprocessing
- HOG feature extraction
- SVM classification
- Confusion matrix evaluation

## Accuracy
Achieved ~80-90% accuracy using HOG + SVM.

## Technologies Used
- Python
- OpenCV
- Scikit-learn
- NumPy
- Matplotlib
